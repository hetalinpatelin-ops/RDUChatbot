# RDU Chatbot Knowledge Base

This folder contains documents that will be processed into the knowledge base.

## How to Use

1. Add your documents (PDF, TXT, MD, DOCX, JSON) to this folder
2. Commit and push to GitHub
3. In the app (admin mode), click 'Process documents/ folder'
4. Documents will be added to the knowledge base

## Supported Formats

- **.txt** - Plain text files
- **.md** - Markdown files  
- **.pdf** - PDF documents
- **.docx** - Word documents
- **.json** - JSON files

## Example Files

You can add:
- Policy documents
- Procedure manuals
- FAQ documents
- Reference materials
- Any text-based content
